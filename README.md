# Bank Marketing com Random Forest

Projeto da disciplina Inteligência Artificial II para prever a assinatura de um depósito a prazo em campanhas bancárias.

## Notebook

- [`notebooks/treino_bank_marketing.ipynb`](notebooks/treino_bank_marketing.ipynb)

O notebook realiza a preparação dos dados, o treinamento do Random Forest, a avaliação das métricas e a análise dos resultados.

## Como executar

Abra o notebook no Google Colab ou Jupyter e execute as células em ordem. O dataset é obtido do UCI Machine Learning Repository por meio de `fetch_ucirepo(id=222)`.
